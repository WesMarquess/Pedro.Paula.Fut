# Personas

As personas representam os principais grupos que usam ou sustentam o FIND MEU ROLE. Cada uma deve orientar decisoes de fluxo, linguagem, dados exibidos e criterios de sucesso.

| Persona | Papel no produto | Objetivo principal |
| --- | --- | --- |
| [Admin](admin.md) | Mantem a plataforma confiavel | Moderar e operar o ecossistema |
| [Turista](turista.md) | Descobre a cidade | Encontrar experiencias confiaveis |
| [Rolezeiro](rolezeiro.md) | Usa a plataforma com frequencia | Encontrar roles alinhados ao seu gosto |
| [Trabalhador](trabalhador.md) | Oferece trabalho freelancer | Encontrar servicos adequados |
| [Empresa](empresa.md) | Publica roles e oportunidades | Atrair publico e contratar profissionais |

## Como usar

- Toda nova funcionalidade deve indicar qual persona atende.
- Uma funcionalidade que afeta mais de uma persona deve documentar o beneficio para cada lado.
- Necessidades de negocio nao devem substituir necessidades reais do usuario.
- As personas sao hipoteses iniciais e devem ser validadas com entrevistas e observacao.
